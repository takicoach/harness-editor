# プロジェクトステータスファイル仕様 `.sme/status.json`

エディタのホーム画面は、各プロジェクトフォルダ直下の `.sme/status.json` を読んで
ステータスバッジ（未着手・編集中・書き出し済・レビュー待ち・公開済）と
「AI 作業中」のライブ表示（工程名＋スピナー）を出し分けています。
自作スキルからこのファイルを更新すれば、作業の進行状況をホーム画面にリアルタイムで反映できます。
AI タブ経由の編集でも、待機役（全体待機・並列版）の文言は編集担当の subagent にこの
`activity` を書かせる運用になっているため、複数動画の「AI 作業中」が同時に表示されます。

このファイルは無くても動作に支障はありません（存在しない・壊れている場合は自動判定に
フォールバックします）。書く/書かないは任意です。

## スキーマ

```json
{
  "stage": "review" | "published" | null,
  "activity": {
    "label": "カット中",
    "startedAt": "2026-07-09T10:00:00Z"
  } | null
}
```

- `stage`: ユーザーがホーム画面のバッジメニューで手動設定する値。
  - `"review"` … レビュー待ち
  - `"published"` … 公開済
  - `null` … 手動設定なし（自動判定に委ねる）
- `activity`: AI が作業中であることを示す値。存在すればバッジより優先して表示される。
  - `label`: 表示する工程名（自由文字列。例: `"カット中"` `"テロップ挿入中"`）
  - `startedAt`: 作業開始時刻。**ISO 8601（UTC）** で記録する（例: `2026-07-09T10:00:00Z`）
- どちらのキーも省略可。ファイル自体が存在しない場合と同じ扱いになる。

## 表示の優先順位

1. **activity**（存在すれば最優先。バッジ＋スピナー＋工程名を表示）
2. **stage**（手動設定があればそれを表示。レビュー待ち／公開済）
3. **自動判定**（stage が `null` の場合のみ）
   - `out/video.mp4` が存在する → 書き出し済
   - 編集用データファイル（カット・テロップ・SE・BGM など）のいずれかが存在する → 編集中
   - どちらでもない → 未着手

## stale（放置）判定

`activity.startedAt` から **2 時間**を超えて同じ activity が残っている場合、
ホーム画面はバッジに「（中断?）」を添えてグレー表示にします（スピナーは止まる）。
スキル側で activity を消し忘れても、実害なく目立つだけなので過度に心配する必要はありません
（ただし完了時にはできる限り消してください。手順は下記）。

## 壊れたファイルの扱い

- JSON として解析できない
- オブジェクトではない
- `stage` / `activity` が想定外の型・値

いずれの場合も **エディタは落ちず、黙って自動判定にフォールバック**します
（コンソールに警告ログが出ることはあります）。書き込み側で厳密なバリデーションを
気にする必要はありません。

## 自作スキルへの組み込み例

作業開始時に `activity` を書き、完了時に消すだけです。`jq` に依存しない `echo` ワンライナーで足ります。

```bash
# 作業開始時（プロジェクトルートで実行）
mkdir -p .sme
echo '{"activity":{"label":"カット中","startedAt":"'"$(date -u +%Y-%m-%dT%H:%M:%SZ)"'"}}' > .sme/status.json

# 作業完了時（activity を消す）
echo '{}' > .sme/status.json
```

**注意**: 上記の完了時ワンライナーは `stage` も一緒に消します。ユーザーが手動で
「レビュー待ち」等を設定済みの場合は、`stage` を保持したまま `activity` だけ消したいことが
あります。その場合は既存ファイルを読んでから書き戻すか（例: Node.js の1行スクリプトで
`JSON.parse` → `activity` を消して `JSON.stringify`）、シンプルに割り切って `stage` の
消失を許容するかをスキルの用途に応じて選んでください。

## エディタ側の他の変更経路

- **UI からの手動変更**: ホーム画面の各カードのバッジをクリックするとメニューが開き、
  「レビュー待ち」「公開済」「自動判定に戻す」を選べます（`stage` を書き換える）。
- **API**: `POST /api/project/status` に `{ "id": "<プロジェクトID>", "stage": "review" | "published" | null }`
  を送ると `stage` のみ更新されます（`activity` は保持されます）。スキルから直接ファイルを
  書く代わりにこの API を叩いても構いません。
