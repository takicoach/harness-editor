# AI接続マニュアル — 0.7 の画面から編集を頼む

編集画面の右上にある **「AIで編集する」** から、Claude Code / Codex に編集を頼めます。画面の画像は2026年9月26日の0.7.0です。

## 1. 使い方

1. 編集したい作品を開き、右上の緑色の帯 **「AIで編集する」** を押します。
2. 使用する AI を選びます。未導入の Claude は **「インストール」**、Codex は **「導入手順を見る」** の案内に従って準備します。
3. 接続後、画面内のターミナルでログインなどの案内に従い、日本語で編集を頼みます。
4. **「編集画面に戻る」** で映像を確認します。処理の結果は上部の **「AIの作業」** でも確認できます。

![ClaudeとCodexが未導入の場合の接続画面](images/guide/ai.png)

例: 「このテロップの誤字を直して」「0:10 からの間を短くして」「このクリップの色を少し暖かくして」。対象の作品と箇所が分かるように伝えてください。

ターミナルへ直接指示する場合、待機モードを開始する必要はありません。外部の編集スキルや受け箱を使う場合は、画面にある **「待機を開始（編集指示を受け付ける）」** を使います。現在の形式に合った指示文が自動で渡されます。

## 2. 0.7 の編集の仕組み

0.7 の作品は、編集内容を `.harness/project.v2.json` に保存します。**AI と人が同じ編集画面の状態を使う**ため、AI はエディターの編集用ツールを通して変更します。

```text
AI に指示する
  ↓
現在の作品と版を確認 → 編集内容を検証 → 変更を適用
  ↓
「AIの作業」で結果を確認 → プレビューで仕上げる
```

**取り込み済みの旧 `telopData.ts` / `cutData.ts` を直接編集しても、新画面の編集内容は変わりません。** 新形式の `project.v2.json` も、AI から直接上書きする運用にはしないでください。人の入力中や未保存の変更と競合した場合は、状態を確認し直してから進めます。

Claude と Codex を切り替える場合、表示される確認内容を読んでから切り替えてください。現在の処理が進行中なら、結果を確認してから行うと取り違えを防げます。

## 3. AI の利用料金と待機

- エディターは無料です。外部 AI の利用料金は、使用するサービスの契約・認証方法に従います。
- 埋め込みターミナルは、既定で API キーに関する環境変数を外して起動します。画面に課金保護の案内が出たら内容を確認してください。
- 作業が終わったら、待機中の AI も停止してください。
- 手動編集・プレビュー・MP4 書き出しだけを使う場合、AI の契約は不要です。

## 4. つまずいた時の Q&A

**Q. AI に頼んだ結果が画面に出ない**

「AIの作業」で実行結果や競合を確認してください。旧ファイルを直接書き換えるスキルの場合は、0.7 の編集用ツールを使うよう修正が必要です。

**Q. 接続できない**

まずエディターが起動しているか確認し、「AIで編集する」を開き直します。未導入・ログイン待ち・版が古いなど、画面に出る案内を確認してください。

**Q. 指示が進まない**

待機モードを使っている場合は、AI が待機しているか、ログインや確認で止まっていないかを確認します。結果が分からない操作は、同じ指示を繰り返す前に作品と「AIの作業」を確かめてください。

## 付録: 自作スキル・別ターミナルから使う

通常は画面内の接続を使ってください。自作スキルを接続する場合、編集に使う MCP ツールの流れは次のとおりです。

1. `editor_projects` と `editor_read` で、対象作品・形式・現在の版を確認する。
2. `sequence-v2` の作品は、読み取った ID と版を使って編集内容を組み立てる。
3. `editor_validate` → `editor_apply` の順に実行する。
4. 返された `runId` を `editor_runs` で確認し、`saved` を確認してから完了とする。

未保存・人の入力中・競合の場合は、状態を読み直します。結果不明の操作を新しい識別子で繰り返してはいけません。

全体待機・専属待機・直列待機の最新の指示文は **[agentPrompts.ts](../src/shared/agentPrompts.ts)** にあります。0.3.1 の「ファイルを直接編集する」待機文は、新形式の作品には使わないでください。
